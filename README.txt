VISHWARAJ DRY FRUITS — WEBSITE STARTER

Files:
- index.html: website content
- style.css: responsive styling and animations
- script.js: menu, scroll reveal, small product enquiry interactions, mouse parallax
- assets/vishwaraj-logo.png: the supplied original logo image, used without redesign
- assets/*-jar.png: the supplied product jar images

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open index.html in a browser. For best results, use a local server or GitHub Pages.

PUBLISH ON GITHUB PAGES
1. Create a new public repository on GitHub, e.g. vishwaraj-dry-fruits.
2. Upload index.html, style.css, script.js and the entire assets folder (keep paths unchanged).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the URL shown in Settings > Pages.

BEFORE GOING LIVE
- Replace generic WhatsApp links (https://wa.me/?text=...) with your business WhatsApp number in international digits, without + or spaces.
- Confirm product names, actual prices, sizes, claims and shipping details.
- The current product buttons open WhatsApp enquiries; this starter does not have a payment gateway, inventory database or fully functional checkout/cart.
- Google Fonts are loaded online; if unavailable, fallback fonts are used.
- The original logo file is included unchanged. The website uses it as an image rather than recreating its lettering.
